Datenschutzhinweise zur Cora-SHK-Demo

Diese Seite ist eine technische Produktdemo. In der derzeitigen Version werden über die Chatoberfläche keine Kontaktdaten abgefragt und keine Chatverläufe durch die Anwendung gespeichert.

Wenn die Live-KI aktiviert ist, wird die vom Besucher eingegebene Nachricht an die Gemini API von Google übermittelt, um eine Antwort zu erzeugen. Bitte geben Sie keine besonderen Kategorien personenbezogener Daten, Zugangsdaten oder vertraulichen Informationen ein.

Der Betreiber muss vor einer öffentlichen Nutzung die Angaben zum Verantwortlichen, die geltenden Rechtsgrundlagen, die Informationen zu eingesetzten Dienstleistern, Speicherfristen, Betroffenenrechten und Kontaktmöglichkeiten ergänzen und rechtlich prüfen lassen. Dieser Text ist ein technischer Platzhalter und keine vollständige Rechtsberatung.
